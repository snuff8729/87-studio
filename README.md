# 87 Studio

NovelAI(NAI) V4 ~ V5를 활용하여 캐릭터 이미지 세트를 효율적으로 생성하고 관리하는 개인용 웹 애플리케이션.
포즈/제스처별 프롬프트 프리셋을 관리하고, 대량 생성 후 즐겨찾기·토너먼트로 최종 이미지를 선별하는 워크플로우를 지원한다.

## 주요 기능

### 생성

- **프로젝트 워크스페이스** — 씬 목록(레일)·보드 보기, 씬 검색/필터, Ctrl/Cmd+K 씬 팔레트, 여러 씬을 골라 장수 지정 후 한 번에 배치 생성
- **씬 팩 / 씬 템플릿** — 포즈·표정 프리셋을 템플릿으로 관리하고 프로젝트에 골라서 적용, 프로젝트 안에서 팩 만들기·이름 변경·순서·씬 이동
- **플레이스홀더 · 번들** — `@{slot:name}`으로 씬별 가변 값, `@{bundle:name}`으로 재사용 스니펫
- **캐릭터 파츠** — 캐릭터·의상 아이템·코디를 라이브러리로 만들어 두고 조합
  - View(앞/옆/뒤)·Framing(전신/상반신/얼굴) 같은 축 조건에 따라 묘사 조각이 자동으로 들어가고 빠짐
  - 옷 겹침에 따른 가림(부위 단위, 일부 가림), 의상 변수(`@{var:color}` 등 코디마다 다른 색)
  - 조합 확인표와 "비어 있음" 표시로 특정 View에서 빠지는 의상을 바로 확인
  - 워크스페이스와 빠른 생성 모두에서 사용, 생성 이미지는 캐릭터·의상·코디·축 값으로 갤러리 필터 가능
- **캐릭터 위치** — 캐릭터별 AI / 랜덤 / 고정 위치, 씬별 오버라이드
- **참조 이미지** — Vibe Transfer, Precise Reference
- **NAI V5 지원** — V5 Curated/Full 포함 전체 모델, SMEA/DYN·VAR+·DECRISP·랜덤 해상도 옵션, 사이드바/설정에 Anlas·사용량 표시
- **빠른 생성** — 프로젝트 없이 바로 생성 (캐릭터 파츠·위치·참조 이미지 포함)
- **생성 큐** — 진행 카드, 일시정지, 드래그 재정렬, 실패 재시도, 서버 재시작 시 자동 복구

### 태그 입력 도우미

- **자동완성** — 정확도 순위, 별칭 → 정식 태그, 세부 카테고리·게시물 수·정보 패널
- **태그 카드** — 커서가 태그에 멈추면 설명·추천·함께 쓰는 태그·대안·등급별 개수 표시, 드래그로 고정 가능
- **Tag Search 창** (Ctrl/Cmd+Shift+F) — 떠 있는 검색 창, 카테고리 탭, 커서 위치에 바로 추가
- **한국어 지원** — 한글로 태그 검색("줄무늬" → `striped`), 한국어 설명과 카테고리 (NAIA2.0 데이터)
- **자연어 검색** (선택) — EmbeddingGemma로 문장으로 태그 찾기, 설정에서 켜고 끄기

### 선별 · 관리

- **갤러리** — 필터 칩(프로젝트·씬·즐겨찾기·별점·태그·프롬프트 태그·최소 승률·축·캐릭터/의상/코디), 일괄 태그, 태그 북마크에 추가, 무한 스크롤
- **이상형 월드컵 · 비교** — 같은 씬 이미지 1:1 랭킹, 나란히 비교
- **일괄 다운로드** — 필터/선택 기반 ZIP, 파일명 템플릿
- **메타데이터 인스펙터** — NAI 이미지에서 프롬프트·모델·설정을 읽어 프로젝트 생성 또는 빠른 생성으로 가져오기 (항목별 선택)
- **태그 갤러리 · 북마크**, **SD Studio 임포트**, **스토리지 정리**
- **다국어** (English / 한국어), **반응형** (데스크톱·태블릿·모바일), 다크 테마

## 기술 스택

- **TanStack Start** (풀스택 React 프레임워크) + **Vite 7**
- **React 19** + **TypeScript**
- **SQLite** (better-sqlite3) + **Drizzle ORM**
- **shadcn/ui** + **Tailwind CSS 4** + **Radix UI**
- **CodeMirror 6** (Danbooru 태그 자동완성, 플레이스홀더/번들 하이라이팅, 컨텍스트 메뉴)
- **Nitro** (프로덕션 서버)

## 시작하기

### 간편 실행 (Node.js 미설치 환경)

```bash
# Linux / macOS
./start.sh

# Windows
start.bat
```

자동으로 Node.js v22를 다운로드하고, 의존성 설치, DB 마이그레이션, 빌드, 서버 실행까지 수행한다. 실행 후 브라우저에서 http://localhost:3000 을 연다.

태그 자동완성·설명·검색에 쓰는 데이터(Danbooru 태그 DB 약 277MB, 한국어 태그 데이터 약 15MB, 자연어 검색 모델)는 **자동으로 받지 않는다.** 필요하면 설정 › 데이터에서 직접 받으면 되고(대시보드에도 안내가 뜬다), 받지 않아도 프롬프트 작성·생성·갤러리는 모두 동작한다. 새 버전이 있으면 같은 화면에서 확인하고 직접 업데이트한다.

### 개발 환경

```bash
pnpm install          # 의존성 설치
pnpm dev              # 개발 서버 (http://localhost:3000)
```

### 프로덕션 빌드

```bash
pnpm build            # 빌드
pnpm start            # 서버 실행
```

### 테스트

```bash
pnpm test             # 전체 테스트 실행 (vitest)
pnpm test -- --watch  # 워치 모드
```

순수 로직 테스트는 각 모듈 옆 `__tests__/`에 있고, 브라우저 스모크 스크립트는 `scripts/smoke/`에 있다 (NAI 호출 없는 Mock 모드 서버에서 실행).

### DB 관리

```bash
pnpm db:generate      # 마이그레이션 생성
pnpm db:migrate       # 마이그레이션 적용
pnpm db:studio        # Drizzle Studio (DB 브라우저)
```

## 사용 플로우

### 프로젝트 기반 (정석)

1. 설정 페이지에서 NAI API 키 입력
2. (선택) 프롬프트 번들 생성 → 자주 쓰는 프롬프트 스니펫 등록
3. 씬 팩 생성 → 씬(포즈/제스처) 추가
4. 프로젝트 생성 → 캐릭터 슬롯 추가 → 프롬프트 템플릿 작성
   - (선택) 캐릭터 라이브러리에서 캐릭터·의상을 만들어 슬롯에 연결하고, 씬마다 View/Framing 지정
5. (선택) 참조 이미지 등록 (Vibe Transfer / Precise Control)
6. 프로젝트에 씬 팩 할당 (스냅샷) → 캐릭터별 오버라이드 편집
7. 씬 선택 (다중 가능) → 배치 생성
8. 갤러리에서 결과 확인 → 즐겨찾기/별점/태그 선별
9. 이상형 월드컵으로 이미지 랭킹 → 최종 이미지 세트 완성
10. 갤러리에서 필터/선택 기반 일괄 다운로드

### 빠른 생성

1. /generate에서 프롬프트 직접 입력 (또는 캐릭터 탭에서 라이브러리 캐릭터·의상 연결) → 참조 이미지 설정 → 즉시 생성 (Ctrl/Cmd+Enter)
